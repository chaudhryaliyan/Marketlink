OPTIONAL PHOTOS
---------------
Put your own photos here and they replace the built-in illustrations automatically:

  hero.jpg   -> big image on the right side of the home page hero (wide, ~1600x900, subject on the right)
  about.jpg  -> image in the "About Us" section and on the login/register pages (~1200x900)

If a file is missing, an illustrated farm/market scene is shown instead. No code changes needed.
