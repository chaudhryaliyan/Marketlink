# MarketLink

MERN farmers-market pickup/pre-order platform.

- Frontend: `marketlink-client/`
- Backend: `marketlink-server/`
- Vercel config: `marketlink-client/vercel.json`
- GitHub/Vercel instructions: `GITHUB_VERCEL_SETUP.md`

The frontend is configured for Vercel as a Vite SPA. Keep secrets in local `.env` files only.
